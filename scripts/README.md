## 编写约定（迁入时照此办理）

1. **一个脚本一件事**，文件名前缀标阶段：`s0*`（形态/配置）· `s1*`（转写）· `s2*`（装配）·
   `s3*`（索引）· `s4*`（向量）· `s5*`（检索）· `s5b/s5c`（对照与灾备）· `verify`（门）。
2. **`--dry-run` 与 `--check` 是标配**：先验后写；`--check` ＝ 重新派生并与在盘件**逐字节比对**。
3. **唯一写路径**：凡派生件，只经 `--tsv/--out` 一个出口写；⛔ 不提供第二处写盘。
4. **报错要带读数**：说「通过」必须同时给数字（件数／字节／命中数），⛔ 只有形容词的「成功」不算。
5. **不许静默降级**：接口失败、缺键、文件不在，都要**显式**记在输出里（例：`SKIP(环境)`），
   ⛔ 不要用「空结果」冒充「无此项」。
6. **签名含变更的自由度**：缓存／幂等类快速路径的签名必须覆盖 模型名 ＋ 输入 id ＋ 文本 ＋ dtype。
